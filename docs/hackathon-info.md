## Tracks

### 1. Agents Track
Build an AI agent capable of independent, meaningful action — real memory, tool use, and reasoning about what to do next, not an LLM API wrapper with a chat window. Strongest submissions push into multi-agent systems: dedicated roles, shared memory state, and long-horizon planning executing a complex workflow end to end.

Examples:
- A research agent that scrapes the web, monitors competitors, and maintains a living brief on its own schedule
- A multi-agent dev team: one writes code, one reviews it, one runs tests, sharing state until the feature ships
- An ops agent that watches inbox/calendar, drafts responses, books follow-ups, escalates only what needs a human
- A procurement agent that compares vendor quotes, negotiates via email, and builds a recommendation with receipts

### 2. Houston Open Data Track
Build with the city's own data (data.houstontx.gov) — a business insight, civic tool, or social impact application. Winning means surfacing something non-obvious from real Houston datasets that someone could act on tomorrow.

Examples:
- Site selection tool combining permit data, 311 complaints, and crime stats
- Flood risk assistant merging drainage/elevation/parcel data
- City services chatbot answering questions from live city datasets
- Dashboard tracking restaurant inspections against 311 food complaints

### 3. Most Commercializable Track
Build something with a clear path to a real business — a defined customer, a reason to pay, and a working product demoable to an investor Monday morning.

Examples:
- Vertical SaaS automating a painful workflow for one industry
- AI service with usage-based pricing wired in
- Consumer app with a working payment flow and a wedge feature
- B2B integration into tools companies already use (Slack, HubSpot, QuickBooks)

## Judging Criteria (100 points total)

Philosophy: judging real, working systems — not slide decks or simple API wrappers.

| Category | Points | Breakdown |
|----------|--------|-----------|
| **Technical Execution & Completeness** | 30 | Completeness (15): runs end to end, live demo, no crashes. Technical Depth (15): real engineering, meaningful architecture, hard problems solved. |
| **Track Fit** | 20 | Meets the specific track's challenge. Submissions that fit any track unchanged score low here. |
| **Value & Impact** | 25 | Insight Quality (13): non-obvious, genuinely useful. Usability (12): a real user could pick it up and act on it tomorrow. |
| **Frontier Factor** | 25 | Creativity (13): novel combination of tools/models/data. Performance (12): optimized for speed/scale/efficiency, holds up beyond the happy path. |
